## 启动与访问

已有 Docker Desktop/Linux 引擎，在根目录 PowerShell 执行：

```powershell
.\infra\start-local.ps1 -EnableRegistration
```

访问 http://localhost:8088 。首次构建需要下载依赖和镜像；浏览器本地数据按 origin 保存，切换设备/地址前自行导出副本。停止、模型环境注入和只更新 web 的命令见 [运行说明](../infra/README.md)。启动脚本不会自动保留未重新注入的模型环境变量；不要在缺少模型环境时重建正在使用的 server。

当前已运行的 8088 服务保持原状，页面退出合成账号。测试只新增过一套独立合成云账号/备份，没有导入覆盖本地训练。其他测试库、进程与随机端口已回收，不需要作为正式运行依赖。

## 接手后需要知道

本地训练数据和云快照不自动同步；下载不是导入，确认草案不是自动覆盖模板。云账号切换不切换本地库。本版入口仅监听本机，手机不能直接访问电脑 localhost，不以本次交付自动授权开放局域网或公网。

模型首批 10 次预算已用完；第二批 30 次使用 29 次。后续新生成可能付费，单任务最多 4 请求；本轮自动收尾只使用模拟模型，不擅自追加。密钥不在源码或交付包内；模型服务未配置时仍可使用备份和分析。

安装式 PWA、手机实机、长期多用户负载、完整前后端回退、异地灾备、建议效果与充分个性化没有全面验证。当前没有 RAG、多轮记忆或分布式高可用，不把这些内容写成已实现成果。

本地源码快照保存在忽略目录 `.cache/delivery/`，附逐文件 SHA-256 清单和 ZIP 摘要，用于标识本次版本；不包含数据库、浏览器备份、凭据、node_modules 或私有模型日志，不代表已 Git 提交或公开发布。
