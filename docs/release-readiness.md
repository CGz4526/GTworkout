## 本版的能力表述

可以表述：用户隔离的版本化云备份、PostgreSQL 持久任务、可恢复训练投影、受约束的工具调用 Agent、草案确认及本地幂等应用。

不能表述：充分个性化的训练教练、已验证训练效果、RAG、多轮记忆、分布式高可用、生产级容量或全面抗注入。模型样本通过约束验证不等于建议质量得到充分证明。

原方案是在另一环境写成，实际已选择 Java 17、Boot 4 与直接 DeepSeek HTTP 适配，未采用 Spring AI；接口契约当前为 Markdown 文档，不宣称已提供自动生成的 OpenAPI。正式交接以本机代码、ADR 和实际报告为准。

## 后续增强，不继续无限扩充本次收尾

前端包体积优化、更多目标/水平输入与建议质量评分、长时多用户负载、完整前后端配套回退、异地备份等可单独排期。若验收发现它们导致本版核心流程不可用，则对应问题转为交付前修复；否则记录边界，不将计划当成已完成。
