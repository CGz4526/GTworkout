## 容器失败证据与恢复步骤

构建在拉取四个基础镜像元数据时失败：auth.docker.io/token 连接超时，日志目标 IPv6 为 2a03:2880:f129:83:face:b00c:0:25de。尚未触及 Dockerfile 的编译步骤。未修改 DNS、代理、系统配置或镜像源。

网络恢复后在项目根目录执行：

```powershell
docker compose -f infra/compose.yaml up --build -d
docker compose -f infra/compose.yaml ps
docker compose -f infra/compose.yaml logs --tail 100 server
```

随后验收两个服务 healthy、入口 localhost:8088、云服务状态、后端停止后静态前端仍可访问。镜像摘要需在成功拉取后记录，当前镜像仅固定版本标签。
