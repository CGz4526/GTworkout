# P1 本机交付与验证

日期：2026-10-16，Asia/Shanghai。结论：账号、会话、版本化原始备份功能已实现；真实 PostgreSQL 验证、三服务 Compose 启动、API 冒烟及重启持久化通过。浏览器视觉回归未完成，不能据此声称全部前端交互已验收。

## 已实现边界

- 注册、标准表单登录、退出、当前用户与会话 CSRF；注册不自动登录。
- 账号规范化、BCrypt、输入字节限制、独立业务身份隔离和有界单实例限流。
- multipart 原始文件校验、原字节 BYTEA、版本化保存、幂等重放、用户行锁内额度仲裁、原文件下载。
- 前端文件摘要预览、账号与时区确认、同意图重试、版本列表与分页、下载。
- 其他标签页切换账号时，X-Expected-User 只用于与认证身份比较，避免确认内容被传入另一账号。
- P1 不创建异步任务，不提供统计或 Agent；projectionStatus=NOT_REQUESTED。

没有修改 Dexie schema、训练保存、归一化、原 JSON 构造/恢复逻辑，也未导入任何真实训练数据。没有操作已有其他项目数据库、容器或卷。当前目录没有 Git 元数据，未做 Git 提交或推送。

## 容器与现场

Docker Desktop 4.73.1、Engine 29.4.3，Linux/amd64。Java 容器限额 512 MiB、数据库 256 MiB、Nginx 128 MiB。入口 127.0.0.1:8088，专用数据库 workout，卷 workout_postgres_data。

基础镜像已在 Dockerfile/Compose 固定官方仓库 digest：Maven 3.9.9/JDK17、Temurin JRE17、Node24.12.0、Nginx1.28.0、PostgreSQL17.6。首次出现 Docker Hub 超时，后续官方镜像拉取、构建与启动均成功；未修改系统 DNS/代理或使用其他镜像源。

现场通过 infra/smoke-test.ps1 创建了 1 个合成账号和 1 份合成备份，并保留在本项目专用库中。脚本只重启带本项目标签的 db/server，不删除账号、文件、容器或卷。镜像再次构建部署后，合成数据仍存在。密码随机生成且未写入源代码、日志或 .env。

Maven 的镜像构建运行 package，不访问 Docker socket；完整 verify 在宿主机使用 Testcontainers，测试容器由其生命周期管理，和开发卷不共享。构建缓存与本机测试日志位于忽略的 .cache/ 或 Docker 构建缓存。
