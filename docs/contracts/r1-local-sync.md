| 文件 | 当前职责 | 账号模式接入要求 |

## 2. 拟议本地新增结构

保持原 exercises/templates/sessions/weights及既有版本不变。在新的Dexie版本中只新增表，版本号先核对实际最高版本，不直接假定是4。以下是逻辑设计，不是已批准的 stores() 实现：

| 表 | 主键/索引 | 内容 |
|---|---|---|
| accountSessions | [accountId+id]；[accountId+localDate] | 已确认serverDocument、serverVersion、最新draftDocument、localRevision、同步状态 |
| accountExercises | [accountId+id] | 动作缓存和创建状态 |
| syncOutbox | [accountId+mutationId]；[accountId+resourceId]；[accountId+nextAttemptAt] | 冻结请求体/摘要、expectedVersion、依赖、尝试次数、lease、状态 |
| syncMetadata | [accountId+key] | deviceId、初始化/启用状态、后续游标，不含会话凭据 |
| sourceMappings | [accountId+sourceId+entityType+legacyId] | 来源摘要、稳定UUID、迁移状态；无ID旧组以首次映射的持久化位置匹配，编辑前先完成映射 |

服务器用户稳定ID用于隔离，不用昵称/email作为分区；仅在已验证登录后解锁对应缓存，不信任本地值作为服务端身份。账户切换清理页面引用、取消旧请求并校验会话代号；返回迟到响应不得写入新账号缓存。

原始账号空间模板/体重/照片如果首版仍本地，需要明确的独立分区设计，不能偷用共享访客表。R3默认这些入口继续在访客空间管理；账号训练可从用户显式选择的本地模板生成无身份引用的名称/动作快照。启用页必须说明限制。

## 3. 本地保存与调度算法

1. 操作开始时捕获accountId及会话代号，读取当前空间；仓储禁止页面直接指定另一个accountId。
2. 同事务更新draft、localRevision和outbox；失败显示“本地保存失败”，不显示成功。不把可持久化数据只留在React状态。
3. 未发送的同资源请求可合并；变为SENDING前冻结payload与mutationId，并持久化。
4. 同聚合最多一个在途请求。若用户继续编辑，更新draft而不改在途payload；确认后将剩余草稿以新version生成新mutation。
5. 服务端响应写回时比较localRevision；有较新编辑则只更新serverDocument/version，不覆盖draft；无新编辑才标SYNCED。
6. 超时保留冻结请求，同键重试。页面崩溃遗留SENDING通过有期限lease恢复，同标签/多标签用原子领取；即便重复发送也由服务端幂等兜底。
7. 401暂停整个账号队列；403 CSRF按既有客户端策略有界刷新，不无限循环；409冲突保留草稿；422保留并显示字段；429/5xx退避。
8. 前台定时、online事件和重新打开页面触发；不依赖手机浏览器一定支持后台同步，应用关闭期间不承诺自动上传。

重试建议1/2/4/8/16/30秒加抖动，单次活跃自动尝试最多6次，之后FAILED可手动重试；断网不持续轮询。实际计数、deadline用合成时钟测试。待同步容量设上限，满额明确阻止新增并提示导出，不驱逐尚未确认记录。

## 4. 迁移与恢复交互

首次登录不改变数据归属，必须选择进入哪个空间。访客训练进行中时不能自动切换。账号有ACTIVE而本地另一条ACTIVE，展示冲突并要求完成/取消，不静默拼接。

导入预览显示目标账号、来源、数量、未支持字段和冲突。生成ID映射后必须先持久化再开始网络提交；重复导入相同来源使用相同映射。若另一设备重复导入相同文件，依赖服务端导入批次与映射保证，不能仅靠本机映射。

导入/升级失败保持访客四表原样；升级本身不联网。缓存重建只能覆盖已确认缓存，不覆盖pending/conflict草稿。无法读取原库、存储满或迁移失败时提供安全错误与既有导出路径，不调用clear()排错。

R3导入开工前必须补齐training_import/source_mapping表与API审阅，不将R2训练创建接口直接当全库导入协议。

## 5. 验收矩阵

| 场景 | 必须结果 |
|---|---|
| 记录一组立刻刷新 | 本地保留，网络恢复可提交 |
| 发送中再改次数 | 旧响应不覆盖新输入，最终上云为新次数 |
| 服务端提交后断连 | 同键重试，只有一份训练/组 |
| 两标签打开同训练 | 不覆盖草稿；冲突可见，服务端版本不丢更新 |
| 退出A登录B | A队列暂停，B看不到A记录，不向B上传 |
| 会话过期 | 本地仍可保存，显示待登录，同账号登录续传 |
| 一次训练取消 | 未发送可取消本地任务；已发送/结果未知必须解析结果并提交CANCELLED |
| 短训练结束 | 不残留云ACTIVE；最后备注/动作编辑先持久化 |
| 数字/日期边界 | 有效组、容量、本地日与旧口径一致 |
| PWA升级有待同步项 | 旧队列请求仍可重放；不因协议变更丢失 |
| 浏览器存储配额不足 | 明确失败；不删除旧记录或假装成功 |
| 新手机登录 | 显示已同步历史，未迁移照片/体重不显示为已恢复 |

测试采用合成数据、真实PG集成、模拟网络故障和实际手机操作。纯文档阶段不运行迁移或回归。实现时按CLAUDE.md及AGENTS.md执行全量数据兼容验证。
