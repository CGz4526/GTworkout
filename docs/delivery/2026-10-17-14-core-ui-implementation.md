# 正式前端核心页面实施简报

日期：2026-10-17。范围：正式React代码与本地构建，不是交互原型。

## 用户可见变化

- 导航精简为训练/趋势/历史/我的，桌面使用侧栏，训练输入保持窄列；冷白亮蓝与蓝黑深色主题，减少错落进场，保留减少动态支持。
- 首页突出开始/继续训练与今日体重；有氧/休息选择收进开始面板。六部位模板点卡片直开，管理时才显示编辑；原个人模板默认折叠。
- 六预设仅在明确开始或编辑时添加模板及缺失动作，事务防止并发重复；已有同ID模板使用用户修改版本，不改旧模板、不在页面读取时自动播种。
- 每日体重明确保存，支持日期补记、同日更新、校验、失败保留输入与取消未保存提示；当前为本机数据。
- 正在训练按动作折叠，重量/次数/RPE保留原滚轮；加组突出显示，减少组/替换/移除动作收进选项。替换只改当前训练，存在已填数据先解释并确认，不改动作库和模板。
- 休息由全屏遮罩改为底部条，支持减30秒、加30秒、跳过及展开加一分钟；减至0结束，不重置默认休息。仍沿用结束时间持久化与原提醒能力。
- 趋势优先力量/有氧分组竖柱，其后月历与真实体重折线；柱图数据表与月历可跳转对应日期历史。容量、部位、有氧汇总放“更多分析”。
- 历史独立保留，日期与类型筛选按需展开、查询参数可恢复；列表更多操作不常驻展开，支持键盘打开记录。我的页集中账号训练、云快照教练、动作库、模板和本机备份。
- 动作部位筛选改为换行，训练中可按名称搜索或新增，不隐藏末尾部位。

- `npm run test:training-sync`：13项通过，覆盖真实仓储/队列的隔离内存IndexedDB。
- `npm run test:contracts`：共享训练日期/有效组/容量夹具通过。
- `node tests/contracts/check-workout-presets.mjs`：5项通过，验证仅显式写入、并发幂等、用户编辑与无关模板保留、六类动作归属及非法预设拒绝；使用独立内存库。
- 浏览器在独立源`http://127.0.0.1:5197/`验证：体重保存/同日改写/补记与曲线；模板直开、重量及RPE、增减组、休息加减/刷新恢复/跳过、替换与新增动作、完成训练后频率/月历更新、月历到历史筛选、修改模板后首页组数更新，以及原生开始面板Escape关闭与焦点恢复。

- 未修改WorkoutDB schema、db/index.ts、CLAUDE.md、备份格式、数据库或凭据；未部署服务器，没有模型调用。
- 账号训练继续复用原仓储/同步器和共享训练页；本批主要浏览器验证本机训练，不能宣称新增完整账号端到端验收或全部52项功能已重新回归。
- 原统计口径保留：频率按日/四周/本月与前两月分桶；体重等仍使用滚动一周/一月/三月，边界差异在更多分析说明，不在本轮默改为7/30/90天。
- 体重与模板仍是本机数据，账号全量实时统计及体重跨设备同步未新增。
- 旧8088运行站点和服务器暂存包仍是旧版；新版通过本地5197预览，构建产物已生成到dist。公开部署仍需单独授权。
